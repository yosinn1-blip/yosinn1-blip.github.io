GAS×スプレッドシート → Shopify CSV

Google Apps Script で、シートの商品行を Shopify の商品CSV（最小列）に書き出す公開サンプルです。EC案件でよく出る「表計算から一括取込」の手間を、固定範囲で見せます。

できること

  • シート1行目のヘッダー（handle / title / body_html / vendor / type / tags / price / sku）を読む
  • Shopify 商品CSVの代表列へ変換してダウンロード
  • handle が空なら title から簡易スラッグを作る

在庫連携・画像・多言語・バリエーション複雑系は入れていません。追加は見積範囲です。

使い方

  1. 新しいスプレッドシートを開き、上記ヘッダーと数行のデータを入れる
  2. 拡張機能 → Apps Script に shopify-csv-from-sheet.gs を貼る
  3. 保存してシートを再読み込みし、メニュー「Shopify CSV」→「書き出し」
  4. Shopify 管理画面の商品インポートで、まず少数行だけ試す

ソース

samples/shopify-csv-from-sheet.gs を開く
