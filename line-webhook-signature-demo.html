LINE Webhook署名の検証デモ

Messaging API の Webhook は、リクエストボディをチャネルシークレットで HMAC-SHA256 し、Base64 した値が x-line-signature と一致するかで真正性を見ます。計算はブラウザ内だけ（送信なし）。

未計算

できること / できないこと

  • できる: 署名の計算と、入力した署名との一致確認（学習・実装確認用）
  • できない: 実際の LINE への送信、友達追加、本番ボットの運用

シークレットを他人と共有しないでください。ページはサーバーへ値を送りません。

なぜ公開しているか

ECや店舗の「注文・予約をLINEへ通知」系は需要がありますが、Webhook署名を落とすとすぐ破綻します。Shopify／自動化案件と同じ「手間の証明」として、検証デモを公開しています。
